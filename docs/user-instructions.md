# Инструкция для пользователя Telegram-бота расчёта зарплаты

## Как начать расчёт
Для запуска расчёта отправьте команду «старт» или нажмите кнопку «Старт» (если она есть).

## Пошаговый диалог
Бот будет задавать вопросы о вашей должности, образовании, опыте, категории, зоне, местности и типе медорганизации. Для каждого вопроса выберите вариант из предложенного меню или введите свой ответ.

## Что делать, если ошиблись
Если вы ошиблись при вводе, просто напишите «старт» — бот начнёт диалог заново.

## Завершение расчёта
После ввода всех данных бот покажет подробный расчёт зарплаты и объяснит, что это предварительная сумма.

## Команды управления
- Если пользователь в любой момент диалога напишет «Выход», бот завершит текущий расчёт и сбросит все введённые данные.
- Если пользователь в любой момент диалога напишет «старт», бот завершит текущий расчёт, сбросит все введённые данные и начнёт новый диалог с самого начала.
Эти команды работают на любом этапе диалога и позволяют быстро управлять расчётом или начать новый.

## Конфиденциальность
Все введённые данные используются только для расчёта и не сохраняются.

## Обратная связь
Если возникли вопросы или проблемы, обратитесь к разработчику (укажите email или Telegram).
