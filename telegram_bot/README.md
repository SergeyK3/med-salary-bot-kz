# Telegram Bot для проекта med-salary-bot-kz

В этой папке находится исходный код Telegram-бота для расчёта заработной платы медработников РК.

## Техническое задание

### Цель
Разработать Telegram-бота для расчёта заработной платы медицинских работников в РК.  
Бот собирает параметры пользователя через вопросы с выпадающими меню и формирует расчёт ЗП на основе логики основного проекта.

### Функционал

1. **Приветствие и описание бота**
   - Уточнить, что расчет ведётся по умолчанию на полную занятость (ставку).
   - Кратко описать возможности бота.
2. **Сбор данных пользователя через вопросы с выпадающими меню:**
   - Должность/группа
   - Категория (разряд)
   - Стаж работы (полных лет)
   - Наличие надбавок (выбрать все применимые):
     - Вредность (да/нет)
       - Если выбрано "да", появляется дополнительное меню выбора вредности:
         - Рентген
         - УЗИ
         - Инфекционное отделение
         - Паллиатив
         - Анестезиология и реанимация
         - Трансфузиология
         - Эндоскопия
         - Физиотерапия
         - Клинико-диагностическая лаборатория
         - Бактериологическая лаборатория
         - Цитологическая лаборатория
         - Морг и патоморфологическая лаборатория
         - Прочее (с уточнением)
     - Экологическое неблагополучие (да/нет)
       - Если выбрано "да", появляется дополнительное меню выбора типа экологического неблагополучия:
         - нет вредности
         - экологическая катастрофа
         - экологический кризис
         - экологическое предкризисное состояние
         - чрезвычайный радиационный риск
         - максимальный радиационный риск
         - повышенный радиационный риск
         - минимальный радиационный риск
         - с льготным социально-экономическим статусом
     - Нет дополнительных надбавок
3. **Расчёт ЗП**
   - Получение коэффициентов и надбавок из базы данных (sqlite/csv).
   - Автоматический расчет на полную занятость (ставку).
4. **Отправка результата пользователю**
   - Детализация расчёта, указание всех учтённых параметров.
5. **Возможность повторного расчёта ("Рассчитать ещё")**
6. **FAQ, контакты, обратная связь**

### Структура вопросов для пользователя

1. **Выберите вашу должность:**
   - Врач
   - Медсестра
   - ... (санитар пока не нужен)
2. **Выберите категорию:**
   - Высшая
   - Первая
   - Вторая
   - Без категории
3. **Стаж работы (полных лет):**
   - Введите конкретное число, например: 11
4. **Есть ли надбавки:**
   - Вредность
   - Экологическое неблагополучие
   - Нет
5. **Если выбрано "Вредность":**
   - Уточните вид вредности:
     - Рентген
     - УЗИ
     - Инфекционное отделение
     - Паллиатив
     - Анестезиология и реанимация
     - Трансфузиология
     - Эндоскопия
     - Физиотерапия
     - Клинико-диагностическая лаборатория
     - Бактериологическая лаборатория
     - Цитологическая лаборатория
     - Морг и патоморфологическая лаборатория
     - Прочее
6. **Если выбрано "Экологическое неблагополучие":**
   - Уточните вид:
     - нет вредности
     - экологическая катастрофа
     - экологический кризис
     - экологическое предкризисное состояние
     - чрезвычайный радиационный риск
     - максимальный радиационный риск
     - повышенный радиационный риск
     - минимальный радиационный риск
     - с льготным социально-экономическим статусом

### Организация проекта

- Бот реализован как подпроект/папка внутри основного проекта `med-salary-bot-kz` (например, `telegram_bot`).
- Основной процесс расчёта (бизнес-логика, база данных) располагается на сервере (API/backend).
- Бот обращается к серверу через API для расчёта зарплаты.
